# 🚀 Estação Espacial Orbit

Projeto de homologação do protocolo espacial em camadas utilizando Git e GitHub.

## ⚙️ Camadas do Ambiente

- **`develop`**: Ambiente de desenvolvimento onde as novas funcionalidades e código base são criados.
- **`stage`**: Ambiente de homologação e testes para validação antes de subir para produção.
- **`main`**: Ambiente de produção contendo apenas código estável e pronto para uso oficial.
